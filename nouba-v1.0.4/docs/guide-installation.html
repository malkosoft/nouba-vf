Installation

Télécharger l'installateur

Récupérez le fichier NoubaSetup.exe fourni par votre revendeur ou depuis votre espace client.

Lancer l'installateur en tant qu'administrateur

Clic droit sur NoubaSetup.exe → Exécuter en tant qu'administrateur. Suivez l'assistant (dossier d'installation, raccourcis, démarrage avec Windows).

Autoriser le pare-feu Windows

Au premier démarrage, Windows affiche une alerte de pare-feu. Cochez Réseaux privés et cliquez Autoriser l'accès pour que les TV et les postes agents puissent se connecter.

Vérifier le démarrage automatique

Nouba Pro s'installe comme service Windows et démarre automatiquement avec l'ordinateur. Aucune action manuelle n'est nécessaire après un redémarrage.

Emplacement des données — Les données (base de données, sauvegardes, fichiers) sont stockées dans C:\ProgramData\Nouba\, séparé du dossier d'installation. Elles sont conservées lors d'une mise à jour.

Premier démarrage

Après installation, Nouba Pro est accessible depuis n'importe quel navigateur sur le PC serveur :

http://localhost:5000

Ouvrir l'interface d'administration

Naviguez vers http://localhost:5000/Admin. Au tout premier démarrage, Nouba affiche le formulaire de création du compte administrateur.

Créer le compte fournisseur

Renseignez un nom, un identifiant et un mot de passe. Ce compte aura un accès technique complet (rôle Fournisseur). Conservez ces identifiants en lieu sûr.

Activer la licence

Rendez-vous dans Admin → Système → Licence et entrez la clé fournie par Nouba Software. La licence détermine le nombre d'agents autorisés.

Créer les services, guichets et agents

Configurez votre organisation via les onglets Services, Guichets et Agents du panneau d'administration. Consultez le Guide Administrateur pour le détail.

Configuration réseau

Nouba Pro écoute sur le port 5000 de toutes les interfaces réseau (0.0.0.0:5000). Tous les appareils sur le même réseau local peuvent s'y connecter.

Trouver l'adresse IP du serveur

Sur le PC Nouba, ouvrez une invite de commandes et tapez :

ipconfig

Notez l'adresse sous Adresse IPv4, par exemple 192.168.1.100.

Tous les appareils (TV, tablettes, postes agents) accèdent ensuite à Nouba via :

http://192.168.1.100:5000
Adresse IP fixe recommandée — Attribuez une adresse IP statique au PC Nouba dans les paramètres de votre box/routeur (ou dans les propriétés de la carte réseau Windows). Cela évite que l'adresse change après un redémarrage et casse les QR codes et les signets.

Changer le port (optionnel)

Pour utiliser le port 80 (URL sans numéro de port) ou un autre port, modifiez la variable d'environnement NOUBA_URLS dans les propriétés du service Windows :

NOUBA_URLS=http://0.0.0.0:80

Écran d'affichage (TV)

L'écran d'affichage est la page publique qui s'affiche sur la TV en salle d'attente. Elle se met à jour en temps réel sans rechargement.

Connecter la TV au réseau

Branchez la TV (ou un PC/mini-PC) sur le même réseau Wi-Fi ou Ethernet que le serveur Nouba.

Ouvrir l'URL Display dans le navigateur de la TV

http://192.168.1.100:5000/Display

Passer en plein écran

Appuyez sur F11 (ou le bouton plein écran intégré à la page) pour masquer la barre d'adresse. L'écran affichera automatiquement les tickets appelés avec annonce vocale.

TV sans clavier — Si votre TV a un navigateur intégré (Smart TV), entrez l'URL directement. Sinon, branchez un mini-PC (Raspberry Pi, NUC, clé HDMI…) qui démarrera automatiquement sur la page Display.

Borne billetterie

La borne est l'interface tactile (tablette, écran tactile ou PC) sur laquelle les clients retirent leur ticket.

http://192.168.1.100:5000/Borne

Recommandations :

  • Utilisez un navigateur en mode plein écran (F11 ou mode kiosk).
  • Sur Android/iOS, ajoutez la page à l'écran d'accueil pour un look application.
  • Désactivez le verrouillage d'écran automatique sur la tablette de borne.
  • Activez l'impression de ticket dans Admin → Paramètres → Imprimante.

Poste agent

Chaque agent accède à son interface depuis son PC, tablette ou smartphone :

http://192.168.1.100:5000/Agent/Login

Les identifiants agent sont créés par l'administrateur dans Admin → Agents.

Imprimante thermique ESC/POS

Nouba Pro supporte les imprimantes thermiques ESC/POS (tickets de caisse) en deux modes :

ModeConnexionUsage
Réseau (TCP)Ethernet / Wi-FiRecommandé — l'imprimante a sa propre IP
Série (COM)USB ou RS232Pour les imprimantes sans carte réseau

Connecter l'imprimante au réseau

Pour le mode TCP : reliez l'imprimante au même réseau que Nouba et notez son adresse IP (affiché au démarrage de l'imprimante ou dans son menu réseau). Port standard : 9100.

Configurer dans l'admin

Allez dans Admin → Paramètres → Imprimante. Activez l'impression, choisissez le mode, entrez l'IP et le port, puis cliquez Tester l'imprimante.

Vérifier le mode d'impression

QR Code : imprime le ticket avec QR code de suivi mobile. Standard : imprime le numéro de ticket uniquement.

Imprimante série (COM) — Vérifiez le numéro de port COM dans le Gestionnaire de périphériques Windows (COM3, COM4…) et le débit en bauds de votre modèle (généralement 115200).

Activation de licence

La licence Nouba Pro détermine le nombre maximal d'agents actifs simultanément. Sans licence valide, le système fonctionne en mode limité.

Ouvrir l'onglet Licence

Dans l'admin (rôle Fournisseur), allez dans Système → Licence.

Noter l'identifiant machine

Communiquez l'Identifiant Machine affiché à l'équipe Nouba Software pour obtenir votre clé de licence liée à ce poste.

Saisir et valider la clé

Collez la clé de licence reçue dans le champ prévu et cliquez Activer. La page confirmera la date d'expiration et le nombre d'agents autorisés.

Licence liée au matériel — La clé de licence est liée à l'identifiant matériel du PC serveur. En cas de changement de machine, contactez Nouba Software pour une nouvelle clé.

Sauvegardes automatiques

Nouba Pro effectue des sauvegardes automatiques quotidiennes de la base de données. Elles sont stockées dans :

C:\ProgramData\Nouba\backups\nouba_AAAAMMJJ_HHMMSS.db

Les 30 dernières sauvegardes sont conservées. Pour restaurer manuellement :

  1. Arrêtez le service Nouba (Gestionnaire de services Windows → Nouba Pro → Arrêter).
  2. Remplacez le fichier C:\ProgramData\Nouba\nouba.db par la sauvegarde choisie.
  3. Redémarrez le service.
Sauvegarde externe — Configurez une copie régulière du dossier C:\ProgramData\Nouba\backups\ vers un NAS ou un disque externe via un script Windows ou un outil de synchronisation (FreeFileSync, robocopy…).

Mise à jour

Effectuer une sauvegarde préalable

Dans Admin → Système → Sauvegardes, cliquez Sauvegarder maintenant avant toute mise à jour.

Lancer le nouvel installateur

Téléchargez et exécutez le nouveau NoubaSetup.exe. L'installateur arrête le service, met à jour les fichiers programme, et redémarre le service. Les données dans C:\ProgramData\Nouba\ ne sont pas touchées.

Vérifier

Ouvrez http://localhost:5000/Admin et vérifiez la version affichée dans la barre latérale.

Dépannage rapide

ProblèmeSolution
Page inaccessible depuis la TVVérifier que le PC Nouba et la TV sont sur le même réseau. Vérifier l'autorisation pare-feu Windows pour Nouba.
Le service ne démarre pasConsulter l'Observateur d'événements Windows (Source : Nouba). Vérifier que .NET 8 est installé.
Imprimante ne répond pasPinger l'IP de l'imprimante depuis cmd. Vérifier que le port 9100 n'est pas bloqué par un pare-feu.
Base de données corrompueArrêter le service, restaurer la dernière sauvegarde depuis C:\ProgramData\Nouba\backups\, redémarrer.
Disque pleinSupprimer les anciennes sauvegardes dans C:\ProgramData\Nouba\backups\. Libérer de l'espace disque. Le tableau de bord admin affiche une alerte quand l'espace est inférieur à 5 %.
Voix TTS muetteVérifier que le volume du PC n'est pas coupé. Dans Admin → Paramètres → Annonces, vérifier que les voix sont activées et que les modèles Piper sont présents (wwwroot/tts/piper/).
