2. Emplacements & données

  • Programme : C:\Program Files\Nouba Pro (exe, wwwroot, voix, cloudflared, lanceurs).
  • Données : C:\ProgramData\Nouba (base nouba.db, nouba.lic, trial.dat, cache TTS, uploads). Persistantes à la désinstallation.
  • Surcharge du dossier de données : variable NOUBA_DATA_ROOT.

3. Déploiement & lanceurs

  • Installateur Inno Setup 6 (nouba.iss). Ajoute une règle de pare-feu (autorise Nouba.exe entrant) et des raccourcis.
  • Lancement sans fenêtre console : Demarrer-Nouba.vbs (exécute Nouba.exe caché + ouvre le navigateur). Arrêt : Arreter-Nouba.vbs (taskkill).
  • Publication : dotnet publish -c Release -r win-x64 --self-contained true.

4. Licence (RSA, liée machine)

  • Format NOUBA2-<payload base64url>.<signature RSA-SHA256>. Le client contient uniquement la clé publique.
  • Le payload lie la licence à un identifiant machine (dérivé de l'adresse MAC physique) : produit, expiration, nombre d'agents, client.
  • Essai 7 jours : trial.dat signé HMAC (anti-modification). Aucune licence n'est embarquée dans l'installateur → tout client démarre en essai.
  • Générateur de clés (clé privée RSA) : outil séparé, à ne JAMAIS livrer au client. Communiquer l'identifiant machine → générer la clé → le client la saisit une fois.
Sécurité critique — La clé privée RSA et le générateur ne doivent jamais être inclus dans une livraison client (ni dans l'exe, ni dans le ZIP, ni dans Git public).

  • Binaire piper.exe + espeak-ng-data + libtashkeel dans wwwroot/tts/piper.
  • Cache des WAV dans DataRoot/tts-cache (jamais dans Program Files, en lecture seule).
  • Annonce pilotée par /State (nom de service localisé) ; SignalR ne fait que déclencher un rafraîchissement (jamais annoncer directement).

6. Suivi QR : local & externe

  • URL construite par ordre : QrFollowPublicUrl (domaine public) > tunnel Cloudflare > IP LAN réelle du PC (jamais localhost).
  • Tunnel : cloudflared.exe bundlé, démarré automatiquement → URL *.trycloudflare.com. Sécurité : middleware qui, pour les requêtes venues du tunnel (en-tête Cf-Connecting-Ip), n'autorise que /suivi.
  • Limite : l'URL du tunnel gratuit change à chaque redémarrage (usage « à la volée » ; pour du fixe, configurer QrFollowPublicUrl).

7. Maintenance & dépannage

  • Migrations : DbMigrator ajoute les colonnes manquantes + corrige les données (idempotent, marqueurs de reset ponctuels).
  • Sauvegarde : copier C:\ProgramData\Nouba.
  • Réinitialiser un poste : supprimer nouba.lic et trial.dat pour repasser en essai (tests).
  • Éditeur inconnu : l'exe n'est pas signé (certificat OV/EV requis pour supprimer l'avertissement Windows).

8. Limites connues

  • Pas de voix tamazight hors ligne (repli français).
  • Prononciation arabe : qualité du moteur espeak (limite du 100 % offline).
  • Tunnel gratuit : URL dynamique, service best-effort.
  • Admin en français (back-office) ; les écrans client sont multilingues.
