Guide d'installation

Nouba Pro
Installer, démarrer et connecter Nouba Pro en quelques minutes. 100 % hors ligne.
Nouba Pro 1.0.4 · Édition Windows 64 bits

1. Avant de commencer

Nouba Pro s'installe sur un seul PC (le « PC serveur »). Les autres appareils (TV, tablette borne, téléphones) s'y connectent via un navigateur, sur le réseau local — aucune installation sur ces appareils.

Aucun prérequis logiciel : ni .NET, ni base de données, ni composant externe. Tout est inclus, y compris les voix d'annonce.

2. Installation (5 étapes)

  1. Double-cliquez sur Nouba-Pro-Setup-v1.0.4.exe.
  2. Windows affiche « Contrôle de compte » → cliquez Oui (c'est cette autorisation qui ouvre le pare-feu pour le réseau local).
  3. Suivez l'assistant : Bienvenue → Dossier → Raccourci Bureau → Installer.
  4. À la fin, laissez cochée « Lancer Nouba Pro » puis Terminer.
  5. Nouba démarre en arrière-plan (aucune fenêtre) et le navigateur s'ouvre automatiquement.
Emplacements — Programme : C:\Program Files\Nouba Pro. Données (base, sauvegardes) : C:\ProgramData\Nouba (conservées à la désinstallation).

3. Premier démarrage

À la première ouverture, créez votre compte administrateur (nom, identifiant, mot de passe). Conservez bien ces informations.

Démarrer / Arrêter

  • Démarrer : raccourci « Nouba Pro » (Bureau) → démarre en arrière-plan + ouvre le navigateur.
  • Arrêter : menu Démarrer → Nouba Pro → « Arrêter Nouba Pro ».

4. Les 3 écrans

Administrationhttp://localhost:5000/Admin
Borne (client)http://localhost:5000/Borne
Affichage (TV)http://localhost:5000/Display

5. Connecter les autres appareils

Tous sur le même Wi-Fi que le PC. Remplacez localhost par l'adresse IP du PC (indiquée dans l'Administration). Exemple si l'IP est 192.168.1.50 :

AppareilAdresse
TV (affichage)http://192.168.1.50:5000/Display
Tablette (borne)http://192.168.1.50:5000/Borne
Mode kiosque — Sur la borne, le bouton « Mode kiosque » passe en plein écran sans barre du navigateur (sortie par Échap).

6. Suivi mobile par QR code

  • Réseau local : le client scanne le QR du ticket → fonctionne sur le même Wi-Fi (pare-feu ouvert à l'installation).
  • Extérieur (4G) : si le PC a Internet, le QR fonctionne aussi hors de l'agence via un tunnel sécurisé automatique (seules les pages de suivi sont exposées).

7. Activation (après l'essai 7 jours)

  1. La page d'activation affiche l'identifiant machine du PC.
  2. Communiquez-le à votre fournisseur Nouba.
  3. Entrez la clé de licence reçue → activé définitivement.
