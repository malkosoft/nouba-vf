1. الغرض والنطاق

يصف هذا الكرّاس سيناريوهات الاختبار ومصفوفة التغطية حسب الوحدة، ويُستخدم إجراءً لعدم الارتداد يُعاد قبل كل تسليم. الهدف: برنامج موثوق، مستقر، بلا ارتداد.

النطاق: الكشك، شاشة العرض، النداءات الصوتية (TTS)، المتابعة عبر QR، الإدارة، موضع العون، الترخيص، الطباعة، السمات، وسلامة قاعدة البيانات.

4. إجراء عدم الارتداد (يُعاد قبل كل تسليم)

  1. البناء: dotnet build -c Release ← 0 خطأ.
  2. التشغيل: افتح /health ← 200.
  3. الكشك/العرض: خذ تذكرة ونادِها ← عرض + نداء واحد باللغة الصحيحة.
  4. متعدّد اللغات: بدّل FR→AR→EN→TZ.
  5. متابعة QR: امسح الرمز (Wi-Fi ثم 4G)، فعّل التنبيهات، تحقّق من 3 مستويات.
  6. الإدارة: احذف خدمة/شبّاك/عون مرتبط ← رسالة واضحة، لا 500.
  7. السمات: بدّل فاتح/داكن/تلقائي/تباين.

5. النتيجة الإجمالية

الحالة: مطابق
