Guide Administrateur

Nouba Pro v1.0.4  ·  Dernière mise à jour : juin 2026

Connexion administrateur

L'interface d'administration est accessible depuis n'importe quel navigateur sur le réseau :

http://[adresse-serveur]:5000/Admin

Il existe deux niveaux de compte admin :

Rôle Fournisseur

Accès complet — configuration technique, licence, diagnostics, gestion des comptes admin. Créé lors de l'installation initiale.

Rôle Client

Accès opérationnel — services, agents, paramètres d'affichage, statistiques. Compte créé par le fournisseur pour le responsable de l'établissement.

Sécurité — Après 5 tentatives de connexion échouées, l'accès est verrouillé 15 minutes. Utilisez un mot de passe fort pour le compte administrateur.

Tableau de bord

Le tableau de bord s'affiche dès la connexion et présente en temps réel :

  • KPIs du jour — tickets émis, en attente, servis, absents, temps d'attente moyen.
  • Comparaison J-1 — évolution par rapport à la veille.
  • Volume horaire — graphique de répartition des tickets sur la journée.
  • Pic d'activité — heure la plus chargée de la journée.
  • Performance par service — tableau de bord par service.
  • Performance par agent — nombre d'appels et tickets servis par agent.
  • Derniers appels — historique des 20 dernières annonces.
Actualisation — Cliquez sur Actualiser (haut de page) pour recharger les statistiques. Le tableau de bord n'est pas temps réel : les chiffres correspondent au moment du dernier chargement.

Gérer les services

Un service représente un type de prestation (Accueil, Consultation, Paiement…). Chaque service a sa propre file de tickets.

Créer un service

Aller dans l'onglet Services

Cliquez sur Ajouter un service.

Remplir les informations

Nom (affiché sur la TV et la borne), Code (1-3 lettres, préfixe du numéro de ticket : "A" → A001, A002…), Couleur (bouton de la borne), Ordre d'affichage.

Noms multilingues (optionnel)

Renseignez les noms en arabe, anglais et tamazight si votre borne est multilingue.

Activer le service

Cochez Actif pour que le service apparaisse sur la borne. Un service inactif est masqué mais ses données sont conservées.

Code unique — Le code du service (ex. "A", "C", "P") doit être unique. Il ne peut pas être modifié après création car il fait partie des numéros de tickets déjà imprimés.

Gérer les guichets

Un guichet est le poste physique où un agent reçoit les clients. Chaque guichet est associé à un service.

ChampDescription
NomEx. "Guichet 1", "Bureau 3"… Affiché sur la TV lors de l'appel.
ServiceLe service que traite ce guichet. Un agent affecté à ce guichet ne traitera que les tickets de ce service.
ActifUn guichet inactif n'est pas proposé lors de l'affectation des agents.

Gérer les agents

Un agent est un utilisateur qui se connecte à l'interface d'appel pour gérer sa file.

Créer un agent

Onglet Agents → Ajouter un agent

Renseignez le nom complet, l'identifiant de connexion et un mot de passe provisoire.

Affecter un guichet et un service

Choisissez le guichet et le service correspondant. Un agent peut être réaffecté à tout moment.

Activer le compte

Cochez Compte actif. Un compte inactif ne peut pas se connecter. Le nombre de comptes actifs est limité par votre licence.

Limite de licence — Le nombre d'agents actifs simultanément est plafonné par la licence. Vous pouvez avoir autant de comptes inactifs que vous souhaitez.

Suivi de ticket par QR code

La fonctionnalité de suivi permet au client de scanner le QR code imprimé sur son ticket et de suivre sa position dans la file depuis son smartphone.

Activer le suivi QR

Paramètres → Suivi mobile → Activer

Cochez Activer le suivi de ticket par QR code. Les QR codes apparaissent sur les tickets imprimés et en confirmation sur la borne.

Activer le mode d'impression QR

Dans Paramètres → Imprimante → Mode, sélectionnez QR Code. Chaque ticket imprimé contiendra un QR code unique.

Tester depuis un smartphone

Demandez un ticket sur la borne, imprimez-le, puis scannez le QR code depuis votre téléphone. Vous devez voir l'état du ticket en temps réel.

Comment ça fonctionne

Chaque ticket reçoit un code public unique de 8 caractères (ex. X7KP2MQ4) généré aléatoirement. Le QR code pointe vers :

http://[serveur]:5000/suivi/X7KP2MQ4

Le téléphone du client rafraîchit l'état toutes les 5 secondes. Il voit sa position dans la file, le guichet auquel se présenter, et une notification visuelle quand son ticket est appelé.

Sur le même réseau Wi-Fi — Si votre borne et vos clients sont sur le même Wi-Fi que le PC Nouba, le suivi fonctionne automatiquement sans configuration supplémentaire.

Suivi depuis l'extérieur — Cloudflare Tunnel

Fonctionnement automatique

Le QR code contient normalement l'adresse locale du serveur (192.168.x.x) — inaccessible depuis une connexion 4G. Nouba Pro intègre un tunnel Cloudflare automatique : si le PC a internet et que cloudflared.exe est présent, le tunnel démarre tout seul au lancement de Nouba et les QR codes pointent automatiquement vers une URL publique.

Aucune configuration n'est requise — il suffit de déposer un seul fichier.

Mise en place (2 étapes)

Télécharger cloudflared.exe

Sur le PC Nouba, téléchargez cloudflared-windows-amd64.exe depuis :

https://github.com/cloudflare/cloudflared/releases/latest

Renommez-le exactement cloudflared.exe et placez-le dans le même dossier que Nouba.exe ou dans C:\Nouba\.

Redémarrer Nouba

Au prochain démarrage, Nouba détecte cloudflared.exe, lance le tunnel et récupère automatiquement l'URL publique. Dans l'administration, le badge en haut à droite passe au vert :

QR internet actif

Tous les QR codes émis ensuite (imprimés sur le ticket et affichés sur la borne) contiennent l'URL publique. Un téléphone en 4G peut les scanner directement.

Vérifier que le tunnel fonctionne

  1. Demandez un ticket sur la borne.
  2. Désactivez le Wi-Fi de votre smartphone (passez en 4G).
  3. Scannez le QR code imprimé sur le ticket.
  4. La page de suivi doit s'ouvrir et afficher votre position dans la file.
Badge dans l'admin
QR internet actifTunnel actif — les clients 4G peuvent suivre leur ticket
QR tunnel…Démarrage en cours (quelques secondes au lancement)
QR localcloudflared.exe absent ou pas d'internet — suivi Wi-Fi uniquement
QR erreurcloudflared trouvé mais le tunnel a échoué (redémarre dans 30 s)
URL temporaire — L'URL xxxx.trycloudflare.com change à chaque redémarrage de Nouba (ou du PC). Les QR codes imprimés avant le redémarrage deviennent invalides, mais les tickets n'ont de toute façon de valeur que pour la journée en cours. Pour une URL fixe et permanente :
  1. Créez un compte gratuit sur cloudflare.com et ajoutez un domaine.
  2. Tableau de bord Cloudflare → Zero Trust → Networks → Tunnels → Créer un tunnel nommé.
  3. Configurez le tunnel pour pointer vers http://localhost:5000.
  4. Dans Admin → Paramètres → Suivi mobile → URL publique, saisissez votre URL fixe. Elle prend la priorité sur le tunnel automatique.
Alternative sans logiciel — Si votre routeur supporte la redirection de port, ouvrez le port 5000 vers le PC Nouba. Renseignez l'URL http://[votre-ip-publique]:5000 dans les paramètres. Demandez à votre technicien réseau.

Sauvegardes

Accessible dans Admin → Système → Sauvegardes (rôle Fournisseur).

Sauvegarde manuelle

Cliquez sur Sauvegarder maintenant. Un fichier nouba_AAAAMMJJ_HHMMSS.db est créé dans C:\ProgramData\Nouba\backups\.

Sauvegarde automatique

Nouba Pro effectue une sauvegarde quotidienne automatique. Les 30 derniers fichiers sont conservés, les plus anciens sont supprimés automatiquement.

Restauration

  1. Arrêtez le service Nouba (Gestionnaire de services Windows).
  2. Remplacez C:\ProgramData\Nouba\nouba.db par le fichier de sauvegarde.
  3. Redémarrez le service.
Avant toute mise à jour — Effectuez toujours une sauvegarde manuelle avant de mettre à jour Nouba Pro, même si la mise à jour est automatique.

Export statistiques CSV

Le bouton Export CSV (haut du tableau de bord) génère un fichier Excel-compatible contenant :

  • Tous les tickets de la journée (numéro, service, statut, heure de création, heure d'appel).
  • L'historique des appels (ticket, guichet, agent, heure).
  • Les statistiques par service et par agent.

Le fichier est nommé nouba_stats_AAAA-MM-JJ.csv. Ouvrez-le avec Excel ou LibreOffice Calc.

Gérer les comptes administrateurs

Accessible dans Système → Comptes Admin (rôle Fournisseur uniquement).

Il est recommandé de créer un compte de type Client pour le responsable de l'établissement. Ce compte a accès aux fonctions opérationnelles (services, agents, paramètres) mais pas aux fonctions techniques (licence, diagnostics).

ActionComment
Créer un compte ClientOnglet Système → Comptes Admin → Nouveau compte → Rôle : Client
Changer le mot de passeSélectionner le compte → Modifier le mot de passe
Désactiver un compteDécocher Compte actif — le compte ne peut plus se connecter mais son historique est conservé.

Alertes système

Le tableau de bord affiche automatiquement une bannière d'alerte dans deux cas :

Disque presque plein

Affiché si l'espace libre est inférieur à 500 Mo ou à 5 % du disque. Libérez de l'espace ou supprimez d'anciennes sauvegardes.

Base de données inaccessible

Affiché si SQLite ne répond pas. Vérifiez l'intégrité du disque et restaurez la dernière sauvegarde si nécessaire.

L'endpoint /health retourne également l'état du système en JSON (utile pour un monitoring externe) :

GET http://[serveur]:5000/health

{
  "status": "ok",
  "version": "1.0.4",
  "uptime_seconds": 86400,
  "db": { "ok": true },
  "disk": { "free_mb": 15000, "total_mb": 500000, "warn": false }
}

Questions fréquentes

Comment changer la langue de la borne ?

Allez dans Paramètres → Borne. Décochez les langues à masquer et définissez la langue par défaut. Les clients verront un sélecteur de langue si plusieurs sont activées.

Un agent peut-il gérer plusieurs services ?

Non — un agent est affecté à un service et un guichet. Pour qu'un agent traite plusieurs services, créez-lui plusieurs comptes ou réaffectez-le entre les services selon les besoins.

Comment réinitialiser la file en début de journée ?

La numérotation repart automatiquement à 001 chaque jour. Les tickets du jour précédent sont conservés dans la base pour les statistiques.

L'écran TV affiche les anciens tickets de la veille

L'écran Display n'affiche que les tickets appelés du jour en cours. Si vous voyez des tickets d'hier, vérifiez que l'horloge du PC serveur est correcte.

Comment savoir si l'imprimante est en ligne ?

Le widget imprimante dans la barre du haut (rôle Fournisseur) affiche un point vert (en ligne) ou rouge (hors ligne). Cliquez dessus pour accéder à la configuration.

Comment ajouter un logo sur les tickets imprimés ?

Allez dans Paramètres → Imprimante → Logo et uploadez une image BMP monochrome (les imprimantes ESC/POS n'impriment pas en couleur).

Les annonces vocales ne s'entendent pas

Vérifiez le volume du PC sur lequel tourne l'écran Display (pas le serveur Nouba, mais le PC branché à la TV). L'annonce est émise par le navigateur de ce PC.

Comment accéder à Nouba depuis un autre bâtiment ?

Si les deux bâtiments sont sur le même réseau (VPN ou MPLS), l'accès est direct via l'IP du serveur. Sinon, configurez un tunnel Cloudflare (voir section ci-dessus) ou une redirection de port sur votre routeur.

Comment voir les statistiques du mois ?

Utilisez l'export CSV quotidien et consolidez les fichiers dans Excel. Une future version intégrera des statistiques mensuelles directement dans l'admin.
