Guide d'utilisation

Nouba Pro v2.1 — Système de gestion de file d'attente · Support : FR · AR · TZ · EN

🎯 Présentation du système

Nouba Pro est un système complet de gestion de file d'attente conçu pour les structures d'accueil du public : cliniques, mairies, banques, agences, préfectures…

🖥️
Borne kiosque
/Borne
Le client choisit son service et imprime son ticket
👤
Poste agent
/Agent
L'agent appelle le prochain ticket et gère la file
📺
Écran TV
/Display
Affiche les appels en cours dans la salle d'attente
⚙️
Administration
/Admin
Configure tous les paramètres du système

🚀 Premier démarrage

1
Lancer l'application
Double-cliquez sur Nouba.exe. Une fenêtre console s'ouvre — ne la fermez pas.
2
Ouvrir l'admin
Dans votre navigateur, allez sur http://127.0.0.1:5000/Admin
3
Créer le compte admin
Au premier lancement, créez votre compte administrateur. Choisissez un mot de passe fort.
4
Configurer les services
Ajoutez vos services (ex: Accueil, Consultation, Paiement) dans l'onglet Services.
5
Créer les agents
Ajoutez un agent par guichet dans l'onglet Agents. Chaque agent a un login et mot de passe.
6
Tester le circuit
Ouvrez la Borne, créez un ticket, puis connectez-vous en tant qu'agent pour l'appeler.
⚠️ Important : Ne fermez jamais la fenêtre console noire — c'est le serveur. Si vous la fermez, le système s'arrête.

🌐 Configuration réseau

Par défaut, Nouba écoute uniquement sur l'ordinateur local (127.0.0.1:5000). Pour que la borne, l'écran TV ou les postes agents soient sur d'autres machines, vous devez configurer l'accès réseau.

Depuis l'interface admin

Allez dans Admin → Système → Configuration réseau et changez l'URL :

Cas d'usageURL à saisir
Tout sur le même PChttp://127.0.0.1:5000
Accès depuis n'importe quelle machine du réseauhttp://0.0.0.0:5000
IP fixe du serveur (ex: 192.168.1.10)http://192.168.1.10:5000
💡 Comment connaître l'IP du serveur ?
Sur Windows : ouvrez l'invite de commande (Win+R → cmd) et tapez ipconfig. L'adresse IPv4 est votre IP locale.

Sur les autres postes (borne, TV, agent)

Ouvrez le navigateur et tapez l'adresse du serveur. Exemples :

InterfaceURL depuis un autre poste
Borne kiosquehttp://192.168.1.10:5000/Borne
Écran TVhttp://192.168.1.10:5000/Display
Poste agenthttp://192.168.1.10:5000/Agent
⚠️ Redémarrage requis après chaque changement d'URL réseau.

🖥️ Borne kiosque

URL : /Borne — Page tactile pour les clients. Recommandé en mode plein écran (F11).

Fonctionnement

  1. Le client appuie sur le service souhaité.
  2. Si les tickets prioritaires sont activés, une option apparaît pour les personnes prioritaires.
  3. Le ticket s'affiche à l'écran avec numéro, service, heure et délai estimé.
  4. L'impression démarre automatiquement si une imprimante est connectée.
  5. La borne revient à l'accueil après quelques secondes (délai configurable).
🖨️ Impression : La borne utilise la boîte d'impression standard du navigateur. Pour une impression silencieuse (sans dialogue), configurez l'imprimante thermique comme imprimante par défaut dans Windows et activez "Impression silencieuse" dans les options avancées du navigateur ou utilisez un logiciel comme PrinterShare ou RawBT.

Fermer la prise de tickets

Dans Admin → Système → Zone dangereuse → Fermer la prise de tickets. Un message s'affiche sur la borne.

👤 Poste agent

URL : /Agent/Login — Chaque agent se connecte avec son identifiant et mot de passe.

ActionDescription
Appeler le suivantAppelle le prochain ticket en attente (prioritaires d'abord). L'écran TV s'actualise instantanément.
RappelerRépète l'annonce d'un ticket déjà appelé sans en prendre un nouveau.
TerminerMarque le ticket comme traité. Il disparaît de la file.
AbsentMarque le client comme absent. Le ticket est archivé.
TransférerEnvoie le ticket vers un autre service (ex: de l'Accueil vers la Consultation).
💡 L'agent ne voit que les tickets de son service assigné. Il ne peut pas intervenir sur les tickets d'un autre service.

📺 Écran d'affichage TV

URL : /Display — À afficher sur un écran dans la salle d'attente en plein écran (F11).

Ce qui s'affiche

  • Le ou les numéros en cours d'appel (avec guichet et service)
  • L'historique des derniers appels
  • Une bannière de texte défilant configurable
  • L'heure en temps réel
  • Une annonce vocale à chaque appel (configurable)

Changer la langue de l'affichage TV

Dans Admin → Textes & Langues → changer la Langue par défaut. L'écran TV s'actualise automatiquement sans rechargement.

🏷️ Gérer les services et guichets

Ajouter un service

Admin → Services → Ajouter un service. Renseignez nom, code (2-3 lettres, ex: "A" pour Accueil), couleur et ordre d'affichage.

Le code est utilisé dans la numérotation des tickets (ex: A001, C002). Ne le changez pas après avoir commencé à émettre des tickets.

Ajouter un guichet

Admin → Guichets → Ajouter un guichet. Associez chaque guichet à un service.

Supprimer un service

Les agents assignés sont automatiquement réaffectés ou désactivés. Les tickets et l'historique du service sont supprimés.

📊 Rapports et statistiques

Rapport journalier (PDF)

Admin → Système → Liens rapides → Rapport PDF journalier. La page s'ouvre avec les KPIs, stats par service et détail complet. Cliquez Imprimer / Enregistrer en PDF dans votre navigateur.

Export CSV

Admin → Système → Export statistiques CSV. Télécharge un fichier CSV du jour avec tous les tickets, importable dans Excel.

Dashboard en temps réel

Le Dashboard Admin se met à jour automatiquement toutes les 10 secondes sans rechargement de page.

💾 Sauvegardes

Nouba sauvegarde automatiquement la base de données toutes les 6 heures. Les 20 dernières sauvegardes sont conservées.

Où trouver les sauvegardes

Admin → Système → Données & Sauvegardes — le chemin exact est affiché.

Sur Windows, c'est généralement :
C:\ProgramData\Nouba\backups\

⚠️ Recommandation forte : Copiez régulièrement le dossier backups sur une clé USB ou un disque externe. En cas de panne du PC, les données seront récupérables.

Restaurer une sauvegarde

  1. Arrêtez l'application (fermez la console).
  2. Allez dans le dossier données (C:\ProgramData\Nouba\).
  3. Renommez nouba.db en nouba.db.old.
  4. Copiez le fichier de sauvegarde souhaité et renommez-le nouba.db.
  5. Redémarrez l'application.

❓ Questions fréquentes

La borne n'imprime pas le ticket automatiquement ?
La boîte de dialogue d'impression doit s'ouvrir automatiquement. Si elle est bloquée, vérifiez que les popups ne sont pas bloqués dans le navigateur. Pour une impression 100% automatique (sans dialogue), configurez l'imprimante thermique comme imprimante par défaut et utilisez Chrome en mode kiosque : chrome.exe --kiosk --kiosk-printing http://127.0.0.1:5000/Borne
L'écran TV ne se met pas à jour en temps réel ?
Vérifiez que le serveur est toujours en marche (console ouverte). Vérifiez que l'ordinateur de l'écran TV est bien sur le même réseau que le serveur. Si le problème persiste, rechargez la page Display (F5).
J'ai oublié le mot de passe administrateur ?
Arrêtez l'application. Supprimez le fichier nouba.db dans C:\ProgramData\Nouba\. Redémarrez — le système vous demandera de créer un nouveau compte admin. Attention : cela efface toutes les données. Faites d'abord une copie du fichier .db.
Peut-on utiliser Nouba sur plusieurs ordinateurs simultanément ?
Oui. Un seul PC fait office de serveur (celui où tourne l'application). Tous les autres postes (borne, TV, agents) accèdent au serveur via le navigateur en utilisant l'IP réseau du serveur.
Comment remettre les compteurs à zéro chaque matin ?
La numérotation repart automatiquement de 001 chaque jour. Vous n'avez rien à faire. Si vous souhaitez effacer les tickets du jour en cours, utilisez Admin → Système → Zone dangereuse → Réinitialiser la journée.
Les annonces vocales ne fonctionnent pas ?
Les annonces utilisent la synthèse vocale du navigateur (Web Speech API). Vérifiez que le son n'est pas coupé, que les annonces vocales sont activées dans Admin → Affichage, et que le navigateur supporte la TTS (Chrome et Edge recommandés). Sur certains systèmes, les voix en arabe ou tamazight peuvent nécessiter l'installation de packs de langue Windows.
